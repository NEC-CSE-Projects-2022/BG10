WasteNet – Smart Garbage Classification System

Real-Time Waste Classification using RepVGG-MEM Model

About the Project

WasteNet is an intelligent waste classification system that uses the RepVGG-MEM deep learning model to classify different types of waste such as plastic, metal, glass, shoes, clothes, and biodegradable waste.

The model achieves 95.06% accuracy after using EMA, Mixup augmentation and structured pruning, making it suitable for smart bins and real-time waste monitoring.

Methodology

The methodology follows a structured pipeline from dataset preparation to the final classification output.

Block Diagram

  • Data Collection: TrashNet, Kaggle Garbage Dataset, PublicGarbageNet
  • Preprocessing: Resizing, Normalization
  • Augmentation: Horizontal flip, Rotation
  • Architecture: RepVGG-MEM with MSCA
  • Performance Boost: EMA + Structured Pruning
  • Output: Predicted waste category

Project Goal

The main goal of WasteNet is to provide an efficient, real-time waste classification model that can be integrated into smart bins, IoT-based waste management systems, and eco-friendly recycling platforms.
