📘 Dataset Description

I used three publicly available garbage classification datasets from Kaggle to build the dataset for this project. These datasets contain images of various household waste items photographed in different environments, enhancing the model’s ability to generalize.

The combined dataset includes categories such as cardboard, glass, paper, metal, plastic, trash, biological waste, clothes, green glass, brown glass, and batteries. Each dataset contributes unique samples, helping create a more diverse and balanced dataset.

To prepare the dataset for training, the images were divided into:

  • 60% for training
  • 20% for testing
  • 20% for validation

This split ensures effective training, fair evaluation, and proper validation using unseen data, helping prevent overfitting and improving overall model performance.
